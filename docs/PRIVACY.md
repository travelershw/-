# 隐私与发布范围（PRIVACY）

## 一、本仓库是什么

本仓库是对外公开发布的 **“完整工程源码 + 历史实现”**，**不是任何一台机器的运行备份**。它只包含代码、配置模板与文档，不包含机器上的个人运行状态。

## 二、本仓库明确“不包含”的内容

- ❌ **运行数据**：数据库（`.db` / `.db-shm` / `.db-wal`）、日志（`.log`）、聊天记录、好感度/记忆存储。
- ❌ **外部图片**：角色立绘、表情包、屏幕截图（`shots/`）等一律不提交。
- ❌ **密钥与令牌**：API Key、NapCat token、共享密钥（secret）、`.env`、真实 `config.txt` / `config.json`。
- ❌ **CA 证书**：`cacert.pem`（请从 curl 官网自行下载，见 INSTALL）。
- ❌ **构建/环境产物**：`.venv`、`__pycache__`、`_build`、`_dist`、`*.exe`、`*.zip` 等。

## 三、身份信息约定

为保护隐私，**所有文档与示例一律不出现**：

- 真实 QQ 号 / 群号（示例统一使用虚构号码 **`10001`**）；
- 真实姓名、昵称或群成员信息；
- 真实机器路径或用户名；
- 真实聊天内容截图或逐字对话。

示例中一律使用 `10001`、`127.0.0.1`、`ws://127.0.0.1:6198` 等占位值。

| 组件 | 数据 | 位置 |

| 桌宠 | 屏幕截图 | 本机 `shots/`（仅保留最近若干张） |

## 五、桌宠会读到本机的什么（传感器）

桌宠有一个"传感器"板块，全部**由你手动触发**，没有后台偷偷采集：

| 功能 | 读什么 | 边界 |
| --- | --- | --- |
| 本机状态（`pc_state.py`） | 闲置时长、是否锁屏、**当前前台程序的进程名**、摄像头设备列表 | **只取进程名，绝不取窗口标题**；每 10 秒一批，只写本机 `pc_state.json`，**不联网、不上传** |
| 摄像头（`camera.py`） | 摄像头画面 | **只有你点菜单「用摄像头看一眼」才会抓**；一次一帧；发送后**默认 60 秒删除**（`camera_keep_frame` 可改成保留）；她只能"提议看一眼"，**提议本身绝不抓拍**，且不会把照片发到群里 |
| 看屏幕（`screen.py`） | 屏幕截图 | 同样只在你点击时抓一张，存本机 `shots/`（默认保留最近 20 张）；图片格式可用菜单在 PNG / JPEG 间切换 |

## 六、唯一会离开本机的传感器数据：天气

"今天天气"会向 **[Open-Meteo](https://open-meteo.com/)** 发两个只读 GET 请求：

- 请求内容：**你填的位置的经纬度** + 要哪些字段；
- 不收：本机任何信息（没有设备标识、没有账号、没有 IP 之外的任何东西）、不需要 API Key、不需要注册；
- 位置**由你自己填**（菜单「设置位置…」填城市名 → 一次性查经纬度后**存在本机配置里**），
  **不会用你的 IP 去反查位置**；
- 服务方可见的只有你的 IP 与所查坐标——**不想暴露就干脆不设位置**（不设时点「今天天气」只会提示你去设，不会发任何请求）。

## 七、桌宠抓屏说明

桌宠"看屏幕"与"看摄像头"都**只在你点击时抓一次**：抓之前会先把桌宠/气泡/聊天窗藏起来
（免得"看到自己"），抓完立刻恢复；截图存本机 `shots/`（默认保留最近 20 张，可切 PNG/JPEG），
摄像头那一帧**发送后 60 秒删除**（除非显式打开 `camera_keep_frame`）。
`config.json` 里的 `screen_capture` / `camera_capture` 可以整体关掉这两个功能。

## 八、桌宠抓屏说明（历史条目，已由上一节取代）

> 早期版本文档曾写"抓屏功能默认关闭"。实际默认是 `screen_capture: true`，
> 但**没有任何定时或后台截图**——抓取永远要你点一次。此处保留说明以免与旧版文档混淆。
