# 隐私与发布范围（PRIVACY）

## 一、本仓库是什么

本仓库是对外公开发布的 **“完整工程源码 + 历史实现”**，**不是任何一台机器的运行备份**。它只包含代码、配置模板与文档，不包含机器上的个人运行状态。

## 二、本仓库明确“不包含”的内容

- ❌ **运行数据**：数据库（`.db` / `.db-shm` / `.db-wal`）、日志（`.log`）、聊天记录、好感度/记忆存储。
- ❌ **外部图片**：角色立绘、表情包、屏幕截图（`shots/`）等一律不提交。
- ❌ **密钥与令牌**：API Key、NapCat token、共享密钥（secret）、`.env`、真实 `config.txt` / `config.json`。
- ❌ **CA 证书**：`cacert.pem`（请从 curl 官网自行下载，见 INSTALL）。
- ❌ **构建/环境产物**：`.venv`、`__pycache__`、`_build`、`_dist`、`*.exe`、`*.zip` 等。

## 三、身份信息约定

为保护隐私，**所有文档与示例一律不出现**：

- 真实 QQ 号 / 群号（示例统一使用虚构号码 **`10001`**）；
- 真实姓名、昵称或群成员信息；
- 真实机器路径或用户名；
- 真实聊天内容截图或逐字对话。

示例中一律使用 `10001`、`127.0.0.1`、`ws://127.0.0.1:6198` 等占位值。

## 四、用户数据默认存放位置（均为“本机”，不进仓库）

| 组件 | 数据 | 位置 |
| --- | --- | --- |
| 桌宠（独立模式） | 设置与 API Key | 本机 `desktop/config.json`（**勿外发**） |
| 桌宠 | 聊天记录、记忆、心情 | 本机 `pet_data.db` |
| 桌宠 | 屏幕截图 | 本机 `shots/`（仅保留最近若干张） |
| 桌宠 | 运行日志 | 本机 `pet_log.txt` |
| AstrBot | 数据库、日志、知识库、插件数据 | AstrBot 数据目录（`data/`、`logs/`、`knowledge_docs/` 等） |

这些目录均已列入 `.gitignore`，不会随仓库分发。

## 五、与身份/知识相关的配置项

| 配置项 | 作用 | 说明 |
| --- | --- | --- |
| `QINGYU_USER_ID` | 桌宠在 AstrBot 里的身份 | 需与 `desktop_pet` 适配器的 `user_id` 一致 |
| `QINGYU_KNOWLEDGE_DIR` | 知识库目录 | 可选覆盖，默认取 AstrBot 知识库路径 |
| `QINGYU_NAPCAT_DIR` | NapCat 安装目录 | 看门狗插件用，仅 Windows |
| `QINGYU_QQ_EXE` | QQNT 的 `QQ.exe` 路径 | 看门狗插件用，仅 Windows |

## 六、桌宠抓屏说明

桌宠“看屏幕”功能**默认关闭**，仅在用户主动点击时抓取一张当前屏幕截图，且只保留最近若干张，用于“看图”能力测试。

## 七、发布前检查清单（避免误传私密内容）

- [ ] 不要提交 `config.json`、`config.txt`、`.env`、任何含真实 Key 的文件。
- [ ] 不要上传 `cacert.pem`。
- [ ] **不要上传旧的 zip / 备份压缩包**（历史压缩包可能夹带当时的运行数据或密钥）。
- [ ] 不要上传数据库、日志、截图、立绘等运行数据/外部图片。
- [ ] 发布前用 `git status` 复核：`.gitignore` 已排除上述目录与文件。
