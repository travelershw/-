# 隐私与发布范围（PRIVACY）

## 一、本仓库是什么

本仓库是对外公开发布的 **“完整工程源码 + 历史实现”**，**不是任何一台机器的运行备份**。它只包含代码、配置模板与文档，不包含机器上的个人运行状态。

## 二、本仓库明确“不包含”的内容

- ❌ **运行数据**：数据库（`.db` / `.db-shm` / `.db-wal`）、日志（`.log`）、聊天记录、好感度/记忆存储。
- ❌ **外部图片**：角色立绘、表情包、屏幕截图（`shots/`）等一律不提交。
- ❌ **录音**：`clips/`（麦克风录下的片段）一律不提交。
- ❌ **模型文件**：`models/`（识别模型 78 MB + 静音检测模型 0.6 MB）是二进制大文件，由使用者自行下载，**不进仓库**。
- ❌ **密钥与令牌**：API Key、NapCat token、共享密钥（secret）、`.env`、真实 `config.txt` / `config.json`。
- ❌ **CA 证书**：`cacert.pem`（请从 curl 官网自行下载，见 INSTALL）。
- ❌ **构建/环境产物**：`.venv`、`__pycache__`、`_build`、`_dist`、`*.exe`、`*.zip` 等。

## 三、身份信息约定

为保护隐私，**所有文档与示例一律不出现**：

- 真实 QQ 号 / 群号（示例统一使用虚构号码 **`10001`**）；
- 真实姓名、昵称或群成员信息；
- 真实机器路径或用户名；
- 真实聊天内容截图或逐字对话。

示例中一律使用 `10001`、`127.0.0.1`、`ws://127.0.0.1:6198` 等占位值。

## 五、桌宠会读到本机的什么（传感器）

桌宠有一组“传感器”，每一项都**由你手动触发**或有明确的开关，没有偷偷采集：

| 功能 | 读什么 | 边界 |
| --- | --- | --- |
| 本机状态（`pc_state.py`） | 闲置时长、是否锁屏、**当前前台程序的进程名**、摄像头设备列表 | **只取进程名，绝不取窗口标题**；每 10 秒一批，只写本机 `pc_state.json`，**不联网、不上传** |
| 看屏幕（`screen.py`） | 屏幕截图 | **只在你点菜单时抓一张**；抓之前先把桌宠/气泡藏起来（免得“看到自己”）；存本机 `shots/`（默认留最近 20 张） |
| 摄像头（`camera.py`） | 摄像头画面 | **只有你点菜单「用摄像头看一眼」才会抓**；一次一帧；发送后**默认 60 秒删除**（`camera_keep_frame` 可改成保留）；她只能“提议看一眼”，**提议本身绝不抓拍**，也不会把照片发到群里 |
| 视频通话（`camera.Session`） | 摄像头**常开**（你显式打开这个模式之后） | 只有**你说完一句话**时，才把**此刻那一帧**跟那句话一起交给她（不是每帧都上传）；帧同样**默认 60 秒后删除**；右上角小窗给你看“她此刻能看到的画面”；关掉菜单立刻释放摄像头，**锁屏自动停** |

## 六、麦克风

麦克风是本项目里**最敏感**的一项，所以规矩也最硬：

| 功能 | 什么时候录 | 录到的东西去哪 |
| --- | --- | --- |
| 「听一句（5 秒）」 | **只有你点这一下**，录固定 5 秒 | 存本机 `clips/`；识别完**立即删除**（`mic_keep_clip` 可改成保留） |
| 「对话模式」 | **你显式打开开关之后**麦克风才常开；由静音检测（Silero VAD）判断“你这句话说完了没有” | 每识别完一句就删除那一段；**她“想/说”期间会自动闭麦**，避免把自己的声音录回来 |

- **默认全部关闭**：`mic_listen` 与 `conversation` 出厂都是 `false`，不点就不录；
- **锁屏不听**：读本机锁屏状态，一锁屏立即暂停采集；
- **会自动退出**：对话模式里连续 `conversation_idle_seconds`（默认 180 秒）没有一句话，
  自动关掉麦克风并取消菜单勾选——不会出现“你走了它还在听一整天”；
- **识别默认在本机做**：`asr.engine = "local"` 时用 sherpa-onnx + 中文 Paraformer 模型与
  Silero VAD，**音频不出这台机器**；
- **想用云端识别也可以**：把 `asr.engine` 改成 `"openai"` 并填好 `base_url` / `model` / `api_key`，
  那时**音频会上传给你选的服务商**——这个取舍由你决定，**默认不是它**；
- 四态可见：待机 / 在听 / 在想 / 在说（菜单可勾选项 + 气泡提示）。

## 六点一、视频通话（常开摄像头）

「视频通话」是**你这边单方面开着摄像头**：她能看到你，你不必看到她（她本来就一直在你桌面上）。

- **默认关**（`video_call: false`），要你显式打开；
- 打开后摄像头**保持开着**，所以你说话的瞬间她就能看到你——而不是等你点一次再等曝光稳定；
- **但只有你说完一句话时才交出一帧**（`camera.Session.snapshot()`），不是每帧都上传：
  这是刻意的，既省 token，也避免"摄像头一直在往外传画面"；
- 交出去的帧按**既有规矩**：`shots/` 里，默认 **60 秒后删除**（`camera_keep_frame` 关掉删除）；
- 右上角小窗显示**她此刻能看到的画面**（就是你自己的摄像头画面，只在本机渲染，不存盘）；
- 关掉菜单立刻 `stop()` 释放摄像头；**锁屏自动停**；摄像头被别的程序占用时如实报错并关掉模式；
- `motion`（画面变化量）只在本机算（缩到 48x48 比灰度差），用来提示"画面在动"，
  **不落盘、不上传**。

## 七、离开本机的网络请求清单

| 功能 | 发给谁 | 内容 | 默认状态 |
| --- | --- | --- | --- |
| 天气 / 空气质量 / 日出日落 | **[Open-Meteo](https://open-meteo.com/)**（免 Key、免注册） | 只发**你填的位置的经纬度** + 要哪些字段；不含设备标识、不含账号 | 开，但**没设位置时一个请求都不发** |
| 地名 → 经纬度 | 同上（其 geocoding 接口） | 你输入的城市名 | 只在你点「设置位置…」时发一次，结果存本机 |
| 与她对话 / 看图 | 你自己配置的模型服务商（如 DeepSeek / 智谱） | 你说的话、她的上下文、截图（若你让她看屏幕） | 开（这是本项目的本意） |
| 语音转文字（仅当 `asr.engine = "openai"`） | 你填的识别服务商 | 录音片段 | **默认关**（默认走本机识别） |
| 模型下载 | hf-mirror / huggingface / GitHub | 只下载模型文件，不上传任何本机信息 | 只在你点「下载本机模型…」时 |

**位置一律由你自己填**（菜单「设置位置…」），**不会用你的 IP 去反查位置**；
不想暴露位置就干脆不设——不设时点「今天天气」只会提示你去设，不会发任何请求。

## 八、抓屏 / 摄像头的默认状态（含一次更正留痕）

- `screen_capture` 默认 **true**、`camera_capture` 默认 **true**，
  但**没有任何定时或后台截图**——抓取永远要你点一次；
- 早期版本文档曾写“抓屏功能默认关闭”，那是**错的**；此处更正，以免与旧版文档混淆。
